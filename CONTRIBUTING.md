# Contributing to TextSnipper

Thank you for your interest in contributing to TextSnipper! We welcome contributions from everyone and strive to maintain a friendly and respectful community.

## Code of Conduct

Please note that all contributors are expected to follow our [Code of Conduct](https://example.com/code-of-conduct) to ensure a welcoming and productive environment.

---

## How to File Issues

If you encounter a bug or have an idea for a new feature, please help us by filing an issue.

- **Bug Reports:** Use the bug report template to provide detailed information including steps to reproduce, environment, and expected vs actual behavior.
- **Feature Requests:** Use the feature request template to clearly describe the desired functionality and use cases.

This helps us manage and address issues efficiently.

---

## Branching Model

- Create a new branch for each feature or bug fix. Use descriptive names like `feature/add-new-snippet` or `bugfix/fix-text-rendering`.
- Keep branches small and focused.
- Submit Pull Requests (PRs) from your feature branches to the main branch.
- Make sure your PRs are small and easy to review.

---
