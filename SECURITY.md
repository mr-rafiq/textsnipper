# Security Policy

## Supported Versions

Security fixes are handled on the latest released version of TextSnipper.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Email Mohamed Rafiq at mohamed-rafiq@outlook.com with:

- A clear description of the issue
- Steps to reproduce it
- The affected TextSnipper version or commit
- Any relevant screenshots or logs

TextSnipper runs OCR and QR recognition locally on macOS. It should not send captured screen content to a server.
